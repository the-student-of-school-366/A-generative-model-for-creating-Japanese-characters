### 5. Генеративная модель для создания японских иероглифов (VAE)
**Технологии**: Python, PyTorch, VAE, KMNIST

- Реализовал Variational Autoencoder (VAE) для генерации изображений японских иероглифов
- Обучил модель на датасете KMNIST (60,000 образцов)
- Реализовал функции потерь (reconstruction loss + KL divergence)
- Создал инструменты для визуализации реконструкций и генерации новых образцов
- Реализовал интерполяцию в латентном пространстве для создания анимаций трансформаций
